# Node mode

Your steps run in Vitest's workers, in Node.js. This is the default: any project that doesn't enable
Vitest's browser mode runs in node mode.

Use it for business logic, APIs and services, or to drive a browser yourself with Playwright.

## Configure

```ts filename="vitest.config.ts"
import { cucumber } from "@lotun/vitest-cucumber";
import { defineConfig } from "vitest/config";

export default defineConfig({
  plugins: [
    cucumber({
      import: ["features/support/**/*.ts", "features/steps/**/*.ts"],
    }),
  ],
  test: {
    include: ["features/**/*.feature"],
  },
});
```

Both are required: `test.include` lists your feature files, [`import`](/reference/options#import)
your support code. Support files load in order: each glob's matches sorted, globs in your order, so
put your World and hooks first if your steps depend on them.
