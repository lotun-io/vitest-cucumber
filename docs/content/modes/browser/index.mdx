# Browser mode

With Vitest's [browser mode](https://vitest.dev/guide/browser/), your steps, hooks and World run in a
real browser page, where they can render, click and read the DOM. It's the same plugin and the same
`@cucumber/cucumber` imports as in node mode.

## Install

<Tabs items={["pnpm", "npm", "yarn"]}>
  <Tabs.Tab>
    ```bash
    pnpm add -D @lotun/vitest-cucumber@beta @cucumber/cucumber vitest @vitest/browser-playwright playwright
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    npm install -D @lotun/vitest-cucumber@beta @cucumber/cucumber vitest @vitest/browser-playwright playwright
    ```
  </Tabs.Tab>
  <Tabs.Tab>
    ```bash
    yarn add -D @lotun/vitest-cucumber@beta @cucumber/cucumber vitest @vitest/browser-playwright playwright
    ```
  </Tabs.Tab>
</Tabs>

Install the browser once:

```bash
npx playwright install chromium               # Chromium only
npx playwright install                        # Chromium, Firefox and WebKit
npx playwright install --with-deps chromium   # with the system libraries the browser needs
```

Use `--with-deps` on CI, or on a Linux machine that never ran a browser.

The rest of the setup is Vitest's own: its
[Playwright provider page](https://vitest.dev/config/browser/playwright) covers the provider's
options (how the browser is launched, its context, timeouts).

## Configure

```ts filename="vitest.config.ts"
import { cucumber } from "@lotun/vitest-cucumber";
import { playwright } from "@vitest/browser-playwright";
import { defineConfig } from "vitest/config";

export default defineConfig({
  plugins: [cucumber({ import: ["features/**/*.ts"] })],
  test: {
    include: ["features/**/*.feature"],
    browser: {
      enabled: true,
      headless: true,
      provider: playwright(),
      instances: [{ browser: "chromium" }],
    },
  },
});
```

The plugin switches to browser mode when `test.browser.enabled` is set in the config. Chromium,
Firefox and WebKit all work.

### Add the plugin's types

In a TypeScript project, name the plugin's types in the `tsconfig.json` that checks your support
code:

```json filename="tsconfig.json"
{
  "compilerOptions": {
    "types": ["@lotun/vitest-cucumber"]
  }
}
```

They type Cucumber's hooks for arrow functions that take the World:
[TypeScript](/guides/support-code#typescript).
