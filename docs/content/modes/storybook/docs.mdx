# Features in docs

A stories file's features on its docs page, with [`featuresOf()`](/reference/api#featuresof) in
[Storybook's docs template](https://storybook.js.org/docs/writing-docs/autodocs#write-a-custom-template).
Storybook's docs are React in every framework, so a block reads them with a hook of two lines:
[`onFeaturesChange()`](/reference/api#onfeatureschange) and `featuresOf()` are what React's
`useSyncExternalStore` takes. In `storybook dev` an open docs page then follows the feature files as
you save them: a feature's new text, a feature added or deleted.

Both examples need Storybook's docs addon, `@storybook/addon-docs`, in `.storybook/main.ts`'s
`addons`: the docs pages and their blocks (`Source`, `Heading`, `useOf`) are its own. The first
shows on autodocs pages, the ones of stories files tagged `autodocs` (here every one, with the
preview's `tags`). `featuresOf()` and `onFeaturesChange()` themselves don't depend on the addon.

```tsx filename=".storybook/preview.tsx"
import { featuresOf, onFeaturesChange } from "@lotun/vitest-cucumber/storybook";
import {
  Controls, Description, Heading, Primary, Source, Stories, Subtitle, Title, useOf,
} from "@storybook/addon-docs/blocks";
import type { Preview } from "@storybook/react-vite";
import { useSyncExternalStore } from "react";
// @ts-expect-error The grammar has no types (drop this line with `@types/react-syntax-highlighter`).
import gherkin from "react-syntax-highlighter/dist/esm/languages/prism/gherkin";
import { SyntaxHighlighter } from "storybook/internal/components";

// Gherkin highlighting in docs code blocks (`<Source language="gherkin" />`).
SyntaxHighlighter.registerLanguage("gherkin", gherkin);

/** A stories file's features, live in `storybook dev`. */
const useFeaturesOf = (storiesFile: string) =>
  useSyncExternalStore(onFeaturesChange, () => featuresOf(storiesFile));

/** The features whose scenarios run on the docs page's stories file. */
const Features = () => {
  const { preparedMeta } = useOf("meta", ["meta"]);
  const features = useFeaturesOf(preparedMeta.parameters.fileName as string);
  if (features.length === 0) {
    return null;
  }
  return (
    <>
      <Heading>Behavior</Heading>
      {features.map(({ fileName, source }) => (
        <Source key={fileName} code={source} language="gherkin" format={false} />
      ))}
    </>
  );
};

const preview: Preview = {
  tags: ["autodocs"],
  parameters: {
    docs: {
      page: () => (
        <>
          <Title />
          <Subtitle />
          <Description />
          <Primary />
          <Controls />
          <Stories />
          <Features />
        </>
      ),
    },
  },
};

export default preview;
```

The `registerLanguage` line is what colors the Gherkin: Storybook's code blocks highlight a fixed
set of languages (JavaScript, TypeScript, JSX, TSX, JSON, YAML, Markdown, Bash, CSS, HTML, GraphQL),
so without it `<Source language="gherkin" />` shows a feature as plain text. It needs
`react-syntax-highlighter` in your dev dependencies (version 15, the one Storybook is built with).
`storybook/internal/components` is a Storybook internal module: check it when you update Storybook.

One feature in an MDX page, with Vite's `?raw` (highlighted by the same line of the preview):

```mdx
import { Meta, Source } from "@storybook/addon-docs/blocks";
import * as LoginFeature from "./Login.feature";
import login from "./Login.feature?raw";

<Meta of={LoginFeature} name="Behavior" />

<Source code={login} language="gherkin" format={false} />
```
